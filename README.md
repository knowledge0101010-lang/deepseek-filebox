# DeepSeek Filebox

**One file that holds an entire filesystem — deduplicated, verifiable, and 900× smaller than the originals.**

`DEEPSEEK-FILEBOX.db` is a single SQLite file that indexes a whole working tree, stores
every unique source file **once** (content-addressed by SHA-256), and keeps large binaries
as fingerprints only. It is a *file box*, not a backup: nothing is copied into a directory
tree, the originals stay where they are.

## Why

Working trees accumulate **copies of copies**: `project/`, `project - copy/`, `project (2)/`,
`.../deepseek/deepseek/deepseek/Code-main/...`. In the measured tree a single file existed
**901 times**. The code that matters is a fraction of a percent of the bytes on disk.

The file box answers three questions cheaply:

1. *What is in this tree?* → one indexed table, no walking when you need a lookup.
2. *What is unique?* → content hashes; duplicates collapse to one object.
3. *Can I get it back exactly?* → every stored object is verified by re-reading the original.

## Quickstart

```powershell
# 1. index (fast: names and sizes only)
python tools/filebox_build.py --phase index

# 2. fill contents (resumable, commits every 500 files)
python tools/filebox_build.py --phase fill --max-mb 8

# 3. look around
python tools/filebox_query.py stats
python tools/filebox_query.py list --tag downloads --limit 20
python tools/filebox_query.py cat "C:\path\to\file.ts"

# 4. prove correctness (re-reads originals, compares SHA-256)
python tools/filebox_ops.py verify

# 5. reduce: exact -> normalized -> near-duplicate clusters
python tools/dedupe_e2e.py

# 6. materialize the deduplicated canonical tree + path map
python tools/diet_build.py
```

Full pipeline in one command:

```powershell
python tools/auto_finalize.py        # fill -> verify -> e2e -> diet -> final report
```

## Architecture

```
core            index / dedupe / verify / canonical   (stdlib only: sqlite3, hashlib)
```

* `tools/filebox_build.py` — 2-phase builder. `index` never reads file contents, so it scales
  to hundreds of thousands of entries; `fill` reads and hashes, and is **resumable**.
* `tools/filebox_ops.py` — `stats`, `dedupe`, `verify` (end-to-end correctness), `canonical`
  (unique objects + `MAP.json`).
* `tools/filebox_query.py` — read-only CLI over the box.
* `tools/dedupe_e2e.py` — three-level reduction:
  **A** byte-identical, **B** normalized-equivalent (BOM / CRLF / trailing whitespace),
  **C** near-duplicate clusters (5-gram MinHash + LSH, Jaccard ≥ 0.90).
* `tools/diet_build.py` — writes the canonical tree (`src/`), the path map, and hard-links the
  box into one place so the same bytes never exist twice.

### Accuracy rule (non-negotiable)

| Level | Meaning | Action |
|---|---|---|
| A | byte-identical (same SHA-256) | **merged** into one object |
| B | equal after normalizing BOM/line endings/trailing blanks | **reported only**; original bytes preserved |
| C | Jaccard ≥ 0.90 clone candidates | **never merged**; reported for human review |

Nothing is deleted. `MAP.json` maps every original path back to its object.

## Verification (two kinds)

These answer different questions, and reporting only one of them would be misleading.

| Check | Command | Question it answers | Measured |
|---|---|---|---|
| **Source re-read** | `python tools/filebox_ops.py verify` | *Does the stored content still match the file on disk?* | 23,168 / 23,168 exact, **0 mismatch** — for the 23,168 originals that still exist. 131,838 originals are **gone from their indexed paths** (moved/deleted after indexing); those cannot be checked this way. |
| **Box self-consistency** | `python tools/box_selfcheck.py` | *Is the box internally intact?* | **12,047 / 12,047 objects exact, ratio 1.0** |

Why the original count dropped: the index was built against paths under `Downloads` and the
`Antigravity` trees; those files were subsequently reorganised/moved by other work on the
machine. **The stored content survived** — that is precisely why the box keeps content rather
than only a path list. Neither check ever produced a hash mismatch.

## Non-goals

* Not a backup product: originals are the source of truth; the box is an index + dedup store.
* Not a parser or refactoring engine: it does not modify the code it indexes.
* Not a secret scanner: use a dedicated tool for that.
